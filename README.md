# Route Stitch

Draw a closed route through every beacon without reusing an edge on a tiny switchback grid.

Turn the wheel to aim and click to move one tile. Travel through every gold beacon before returning home. An edge can be traversed only once. Start undoes one move. Click after closing a valid loop to open the next board. Hold Start restarts the current board.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
